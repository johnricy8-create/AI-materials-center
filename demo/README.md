# AI 素材中心 · 前端

这是项目前端，既能作为 M0 高保真 Demo 独立运行，也会在本地后端可用时自动切换为真实数据。

## 运行

先启动后端（见 `backend/README.md`），再启动前端：

```bash
cd demo
npm install
npm run dev
```

打开：

```text
http://127.0.0.1:5173/#/
```

后端地址通过 `VITE_API_BASE` 配置，默认：

```text
http://127.0.0.1:8000/api/v1
```

如果后端未启动，前端自动回退到内置 Demo 数据，并在侧栏显示 `DEMO · 模拟数据`；连接成功后显示 `LIVE · SQLITE`。

生产构建：

```bash
npm run build
npm run preview
```

## 已实现页面

| 路由 | 页面 | 可体验内容 |
| --- | --- | --- |
| `/#/` | 总览 | 统计、最近素材、AI 洞察、待处理素材 |
| `/#/library` | 素材库 | 真实素材、筛选、搜索、详情抽屉、真实上传 |
| `/#/search` | 智能搜索 | 后端关键词检索、匹配理由、相关度、无结果状态 |
| `/#/copilot` | AI 工作台 | 真实 LangGraph 任务、引用素材、文案编辑与复制 |
| `/#/tasks` | 任务中心 | 真实任务列表、节点 trace、失败重试 |
| `/#/settings` | 设置 | GLM 配置说明、SQLite 状态、存储与检索开关 |

## 建议体验路径

1. 在素材库点击任意图片，查看 AI 摘要、标签、分块与任务记录；
2. 打开上传，选择真实文件或点「使用示例文件试试」，观察上传与解析状态；
3. 进入智能搜索，搜索「适合夏季防晒霜的清爽场景图」，查看 AI 理解与匹配理由；
4. 搜索「无人机航拍海景」，查看无结果状态；
5. 进入 AI 工作台，点击示例需求，观察执行步骤、引用素材与可编辑文案；
6. 进入任务中心，打开失败任务并点击重试；
7. 打开设置，确认 GLM-4.7-Flash 与 SQLite 临时方案。

也可以直接打开生成后的演示状态：

```text
http://127.0.0.1:5173/#/copilot?demo=run
```

## 说明

- 后端可用时，素材库、上传、详情、搜索使用 FastAPI + SQLite 真实数据；
- 后端不可用时，自动回退内置 Demo 数据，方便单独预览视觉；
- **API Key 不会写入前端**，只存在于 `backend/.env`；
- 当前数据库为临时 SQLite，M3 接入 sqlite-vec，后续迁移 PostgreSQL + pgvector；
- 图片来自 Unsplash / Pexels，仅用于演示，上线前替换为真实素材；
- AI 工作台会创建真实 Agent 任务，任务中心读取真实 trace；
- 分享/回看任务：`/#/copilot?task=<task_id>`；
- 键位：`⌘K` / `Ctrl+K` 打开命令面板，`Esc` 关闭弹层。
